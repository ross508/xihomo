# xihomo

A minimal, native macOS GUI for [Mihomo](https://github.com/MetaCubeX/mihomo).

The X is a little nod to OS X, the former name of macOS.

xihomo lives in the menu bar and the Dock; the Dock icon can be set to show only while its window is open. It runs Mihomo with your profiles, switches modes and nodes, and turns the system proxy on and off. It runs without administrator rights and does not support TUN.

Requires macOS on Apple Silicon.
